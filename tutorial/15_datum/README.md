# 进阶 · 坐标系基准（datum）：为什么"只换椭球"等于没转换

> 📖 配套读源码讲义：[`docs/teaching/15_datum.md`](../../docs/teaching/15_datum.md)（读源码式讲解，讲清楚"为什么这么写"；与本科小程序同号对应）

**目标**：亲手把 `src/utils/datum.c` 的核心数学（ECEF + 三参数赫尔默特 + 高斯-克吕格）重新实现一遍，亲眼看到：

1. 同一个物理点，在 北京1954 / 西安1980 这类"参心坐标系"下，经纬度会和 WGS84 差出几十到一百多米；
2. 参心坐标系原点偏离地心近 200 m，**必须靠平移参数体现**——"仅换椭球"（平移按 0）等于没转换（XA80 水平差仅 0.019 m）；
3. **"EPSG 没登记 XA80↔WGS84" ≠ "没有参数"**：公开文献有全国统一 3 参数，且能被国测局公布的图幅平移量区间**交叉验证**（落在区间内才可信）；
4. 方里格（高斯-克吕格公里网）与经纬网是两套**不同**的网格——在视图里一个是弯的、一个是直的。

**运行**：
```bash
gcc -std=c11 -O2 -Wall -o tut main.c -lm && ./tut ; echo "exit=$?"
```

**你会看到**：
- 打印 `BJ54`/`XA80` 的地心三参数（米），以及北京在两种基准下的水平偏移（BJ54 约 63.6 m、XA80 约 114 m）。
- 打印西安80 的**双重证据交叉验证**：WGS84→XA80 与 XA80→WGS84 两个方向（三参数常量平移，二者严格反对称），并以 XA80→WGS84 方向对国测局区间判据 → **命中 / 命中**（北 +9.8 m / 东 +113.8 m，均落在北[−9,+43]、东[+76,+119]）。
- 打印北京的高斯-克吕格坐标（lon0=117° 3° 带），并把"灰=经纬网(直) / 蓝=方里格(弯) / 红=北京"写成 `datum.bmp`。

**本目录刻意复刻的真实工程要点**：

| 玩具例子 | 真实工程类比（生产实现见 `src/utils/datum.c`） |
|---|---|
| 三参数平移 `BJ54_T`/`XA80_T` | `DatumDef` 参数表（`datum.c` 的 `DATUMS`），BJ54=EPSG:4214 默认 TOWGS84，XA80=赵玉明等 2013 全国拟合值 |
| `geod_to_ecef`/`ecef_to_geod` | `datum.c` 同名函数（Bowring 闭式反算，精度 ~mm） |
| `wgs84_to_datum` / `XA80→WGS84 = −(WGS84→XA80)` | `datum_wgs84_to` / `datum_to_wgs84`（用真正的矩阵逆，旋转/尺度一填就严格互逆） |
| `gauss_fwd`/`gauss_inv` 画方里格 | `datum_gk_forward`/`datum_gk_inverse`（驱动 Qt 前端的方里格叠加层） |
| 交叉验证"命中/不中" | `datum.c` 顶部长注释的"独立交叉验证"：文献参数 + 国测局区间互印才落值，否则宁可不换基准 |

**交付要求（和真实工程一致）**：
1. 跑通本程序（零 warning），确认交叉验证两项都"命中"。
2. 能说清"为什么内部几何永远是 WGS84、切基准只移动读数网格不重投影底图"这条不变量在 `datum.h` 的注释里怎么写的。
3. 能解释"EPSG 没登记 ≠ 没参数"——为什么需要"文献参数 + 官方区间"两条独立证据，而不是只看一条。

**练习（动手把玩具变成真的）**：
- **负向对照**：把 `XA80_T` 改成某个分区参数（如 西北 −107.61/−45.58/+8.40），再跑——你会发现国测局区间判据**不再两项都命中**（分区参数在泾阳一带不中），这就证明判据真的守住了"只能放全国统一值"这条纪律。
- **补全反向接口**：在 `main.c` 里补一个 `datum_to_wgs84`（ECEF 上加平移 `Xw = Xs + T`，再投 WGS84 椭球），用它直接算出 XA80→WGS84 偏移，验证与"取负号"结果逐位一致（证明常量平移下两方向严格反对称）。
- **加一条判据**：把"北偏移 ∈ [−9,+43] 且 东偏移 ∈ [+76,+119]"写进一段 `assert`-风格检查，作为该参数的回归锁（参考 `skedaddle_datum_selftest` 的做法）。
- 完成后 `git commit` + `git push origin main`（本项目铁律：完成即提交推送）。
