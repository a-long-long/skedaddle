# 第 0 课 · 最小框架（地基）
> 分类：核心代码

> 📖 配套读源码讲义：[`docs/teaching/00_overview.md`](../../docs/teaching/00_overview.md)（读源码式讲解，讲清楚“为什么这么写”；与本科小程序同号对应）


**目标**：在不动项目 `src/` 一行代码的前提下，搭出"一块像素缓冲 + 画点 + 画线 + 写 BMP"
的最小可运行程序。**本小程序自成一体**：`tutorial/01_*` 起的各课是各自独立的单课程序，
并不在这块缓冲上逐课累加；要看「同一份工程从最小框架逐课长大、末课对上 `src/`」，走
[`tutorial/mini/`](../mini/README.md) 演化链（18 个连续快照 + 17 个相邻 diff，本课即 `steps/step00_frame/`）。

**为什么从这里开始**：本项目 Qt 前端与离屏两套前端共用同一个 C 渲染核心，而那个核心最底层的
"画布"就是一块 `uint32_t` 像素缓冲（见 `src/ui/offscreen_shot.c`）。先把这块缓冲摸透，
后续的坐标、投影、渲染管线才有地方"落笔"。

**运行**：
```bash
gcc -std=c11 -O2 -o tut main.c
./tut            # 生成 out.bmp
```

**你会看到**：米白背景上画了一个十字（横/纵轴）和一条对角线。这只是一个"能写图的画板"，
但它是后面所有课的地基。

**关键不变量（贯穿全教程）**：
- 像素缓冲约定 `0x00RRGGBB`，与项目 `offscreen_shot.c` 一致。
- 出图零依赖 SDL/Qt：纯内存缓冲 + 内建 24 位 BMP 写出（这一课已经演示了）。

量化成整数（项目用 1e-7 度的 int32），再谈投影与测距。
