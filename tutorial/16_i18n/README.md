# 进阶 · 极简多语言（i18n）：为什么"中文是 msgid"是安全的

> 📖 配套读源码讲义：[`docs/teaching/16_i18n.md`](../../docs/teaching/16_i18n.md)（读源码式讲解，讲清楚"为什么这么写"；与本科小程序同号对应）

**目标**：亲手把 `src/i18n/i18n.c` 的核心思想重新实现一遍，亲眼看到：

1. **中文是 msgid（原文）**——`i18n_tr("设置")` 在中文模式下直接返回 `"设置"`，不引入任何字符串变化；因此既有的像素/UI 自检在 zh 模式下行为与改前完全一致（这是它能"无侵入"接入回归体系的关键）。
2. **缺译回退链**：zh → 外部 `lang/<code>.xml` → 内置英文 `TR[]` → 中文原文，**任何情况下都不返回空串**。
3. **加一门语言只要三步**：枚举加一项 + 元数据表加一行 + 提供一份 `lang/<code>.xml`。
4. **运行时文件覆盖内置**：手改 `lang/<code>.xml` 即时生效，覆盖代码里的内置翻译。

**运行**（从本目录运行，使相对路径 `lang/` 可被找到）：
```bash
gcc -std=c11 -O2 -Wall -o tut main.c && ./tut ; echo "exit=$?"
```

**你会看到**：
- `[A]` 中文模式：`i18n_tr("设置")` 原样返回 `"设置"`（零变化）。
- `[B]` 英文模式未加载文件：靠内置 `TR[]` 得到 `"Settings"`。
- `[C]` 英文模式加载 `lang/en.xml`：`"设置"` 被文件覆盖成 `"Preferences"`（其余缺译回退内置英文）——演示"文件优先于内置"。
- `[D]` 内置也没有的串：回退中文原文 `"这个按钮没有译文"`，**绝不空串**。
- `[E]` 法语模式：仅译了 `"搜索"→"Rechercher"`，`"退出"` 缺译回退内置英文 `"Quit"`。

**本目录刻意复刻的真实工程要点**：

| 玩具例子 | 真实工程类比（生产实现见 `src/i18n/i18n.c`） |
|---|---|
| `g_langs[]` 元数据表 | `i18n.c` 的 `g_langs[]`（索引 = `I18nLang` 枚举值，`code==NULL` 表示中文无文件） |
| `g_tr[]` 内置兜底表 | `i18n.c` 的 `TR[]`（约 400 条，全条目都有英文，作文件缺失/损坏兜底） |
| `load_pack` 解析 `<item>` | `i18n_load`：还还原 `&amp; &lt; &gt; &#NNN;` 等实体，并支持 `lang/`、`exe_dir/lang/`、裸文件三处候选路径 |
| `tr()` 回退链 | `i18n_tr()`：`zh→文件→内置英文→中文`，中文模式早返回原文 |
| `lang/en.xml` 覆盖内置 | 真实 `lang/*.xml` 由 `scripts/export_lang.py`（从 `TR[]` 导出）生成，或手改覆盖 |

**交付要求（和真实工程一致）**：
1. 跑通本程序（零 warning），确认五个场景输出符合预期（尤其 `[C]` 的覆盖与 `[D]` 的回退）。
2. 能说清"为什么中文模式零变化、为什么缺译回退到原文而不是空串"这两条不变量写在 `i18n.h` 顶部注释里。
3. 能照着 `g_langs[]` + `load_pack` 描述"加一门语言"的三步，并指出真实工程的第四步（运行 `scripts/export_lang.py` 导出该语言基线包）。

**练习（动手把玩具变成真的）**：
- **负向对照**：把 `g_tr[]` 里 `"设置"` 的内置译文删掉、并且让 `lang/en.xml` 也不存在，再跑——`[B]`/`[C]` 应回退到中文 `"设置"`，这证明"绝不空串"判据真的起作用（对照 `i18n.c` 的 `return zh` 兜底）。
- **加一门语言**：在 `g_langs[]` 加 `LANG_DE` 一行、写一份 `lang/de.xml`（如 `<item><zh>搜索</zh><de>Suchen</de></item>`），把 `load_pack` 的 `extract_tag(it, ite, code)` 改成取对应标签——验证德语 `"搜索"→"Suchen"`。
- **接回真实库**：把本程序改成 `#include "i18n/i18n.h"` 并链接 `skedaddle_i18n`，用真实 `i18n_set_lang/i18n_tr` 跑同样五个场景（注意真实库从 `exe_dir/lang/` 取文件，需 `-DLANG_DIR=...` 或把 `lang/` 放到可执行同目录）。
