- ★★★ **交叉编译时 `WIN32` 恒 false**（描述 target=Android），判宿主必须 `CMAKE_HOST_WIN32`。桌面 CMakeLists 用 `WIN32` 成立只因其 target 就是 Windows。Android CMakeLists 已加 host 分支：Windows 走 `protoc --plugin=protoc-gen-c=... --c_out=`，Linux 用独立 protoc-c。MSYS2 的 `protoc-c.exe` 与 `protoc-gen-c.exe` 是同一份插件二进制(369305B)，不认 `--c_out`。写错的症状很隐蔽：CMake 配置不报错，ninja 执行才抛 `Unknown option: --c_out`。
