# 第 14 课 · 极简多语言（i18n）：为什么"中文是 msgid"是安全的
> 分类：核心代码

> 模块：`src/i18n/i18n.{c,h}`（库 `skedaddle_i18n`）、`lang/*.xml`、`scripts/export_lang.py` / `scripts/gen_lang.py`
> 配套小程序：[`tutorial/14_i18n`](../../tutorial/14_i18n)（自包含重实现，可独立 `gcc` 跑）
> 前置：第 1 课坐标与大地基准、第 13 课 datum（基准读数名也走 i18n）。**不依赖第 16 课 Qt 前端**——
> `skedaddle_i18n` 是叶子库，Qt 只是调用方之一；显示层接线放在跨平台段第 16 课，属本课的**下游**而非前置。

## ① 教学目的

本工程是一个**中文原生**的离线地图程序，却要面向英文/法文/日文等多语用户。本课讲清它如何用**不到 700 行 C** 做到"零侵入多语言"，重点不在 API 有多少，而在两条设计不变量：

1. **中文是 msgid（原文）**——代码里写 `i18n_tr("设置")`，中文模式下直接返回 `"设置"`。这意味着：
   - 源码里的 UI 串对开发者**始终可读**（永远是中文），翻译是纯增量、不污染源码；
   - **默认的 zh 模式等于"没装 i18n"**——既有的像素/UI 自检（断言中文串、中文渲染）行为与接入 i18n 前**逐字节一致**。这正是它能"无侵入"挂进一个已有一整套回归的工程的根本原因（见第 11 课纪律）。
2. **缺译回退链，且绝不返回空串**：`zh → 外部 lang/<code>.xml → 内置英文 TR[] → 中文原文`。任何一门语言缺了某条译文，都不会出现空白按钮，而是优雅回退。

学完本课，应能照着"三步"给程序加一门新语言，并说清 i18n 为什么没有破坏"核心零 SDL / 纯 DAG 分层"这两条工程纪律。

**运行时接线（显示层才调，核心不碰）**：
- `src/ui/window.c:62,324`：从 `settings.ini` 的 `lang` 键读整数 → `i18n_set_lang(...)`（C 自绘 chrome/菜单也吃这套）。
- `src/ui_qt/main_window.cpp:109`：`i18n_set_lang_dir(applicationDirPath()+"/lang")`——**必须在 `i18n_set_lang` 之前设置**，英文模式才会优先用外部文件；`:112` 才真正切语言。Qt 侧用 `trc(zh)`/`trd(zh)` 薄包装 `QString::fromUtf8(i18n_tr(zh))`。
- `src/utils/datum.c:339-353`：基准读数名（"Beijing 1954" / "Xian 1980" 等）也走 `i18n_tr`——所以第 13 课 datum 的网格/读数标签会随语言切换（这是 i18n 的"下游"之一）。

## ③ 怎么实现（核心教学点）

### 3.1 不变量：中文是 msgid，zh 模式原样返回

`i18n_tr` 第一行就是：

```c
const char *i18n_tr(const char *zh) {
    if (!zh) return zh;
    if (g_lang == I18N_ZH) return zh;   /* 中文模式：原文返回 */
    return tr_lookup(zh);
}
```

`zh` 串同时承担**两个角色**——既是代码里写死的字面量，又是查表 key。因此：
- 默认语言（中文）下，调用点 `i18n_tr("设置")` 与直接写 `"设置"` **完全等价**；
- 新增任何一门语言，**不需要改任何调用点**，只需让该语言多一份映射。

这正是它比"msgid 用英文、中文反而是翻译"的方案更适合中文原生项目的地方：源码可读性 + 默认零变化 + 增量翻译三者兼得。

### 3.2 回退链：文件优先，内置英文兜底，中文收底

`tr_lookup`（`i18n.c:628`）的顺序是：

```c
for (文件加载的 g_pairs) if (命中) return;        /* lang/<code>.xml 优先（手改覆盖内置）*/
for (内置 TR[])        if (命中) return;        /* 全条目都有英文 */
return zh;                                       /* 缺译：回退中文原文，绝不空串 */
```

关键纪律：**最后一步 `return zh` 保证任何字符串都不会变成空指针/空串**——最坏情况只是"显示中文"，而绝不会出现空白 UI。这是多语言系统最容易翻车的地方（空串 → 控件塌陷），本工程用一行早返回堵死。

### 3.3 运行时文件加载：手改 lang 即时生效

`i18n_load`（`i18n.c:573`）读 `lang/<code>.xml`，每条 `<item><zh>…</zh><code>…</code></item>` 解析成一对 `(zh, 译文)`，追加进动态表 `g_pairs`。它有三处候选路径（exe 目录优先，再回退相对 `lang/`、裸文件名），文件缺失/损坏则 `g_pairs` 保持空、自动用内置 `TR[]`。

`xml_decode`（`i18n.c:476`）还原 `&amp; &lt; &gt; &quot; &#NNN; &#xHH;`，所以语言包里含 `&` `<` `>` 的串（如菜单 `Menu(&M)`）也能正确还原——这是"序列化数据 ≠ C 字符串"的又一次反面教材（呼应第 2 课 PBF stringtable 的坑）。

### 3.4 加一门语言：三步 + 两个导出脚本

1. `i18n.h` 的 `I18nLang` 枚举加一项（如 `I18N_KO = 8`）；
2. `i18n.c` 的 `g_langs[]` 加一行 `{ I18N_KO, "ko", "한국어" }`；
3. 提供 `lang/ko.xml`（`<item><zh>中文</zh><ko>…</ko></item>`）。

配套脚本自动维护语言包：
- `scripts/export_lang.py`：从 `i18n.c` 的 `TR[]` **导出** `lang/en.xml`（内置英文的权威源）；只在翻译源变动后运行，**会覆盖**手改，故手改前要先备份。
- `scripts/gen_lang.py`：以 `lang/en.xml` 的 zh key 列表为"覆盖度检查基准"，生成 `fr/de/es/pt/it/ja` 六份——只含显式翻译的条目，缺译运行时回退英文（专有名词如国名、以及 `[Contours]` 日志行**故意不翻**，回退英文即可）。

> 当前 7 种非中文语言包（en/fr/de/es/pt/it/ja）就是这样来的；中文无文件，因为它就是原文。

## ④ 与其他功能的联系

- **调用方 · 第 16 课 Qt 前端（跨平台段，实现顺序在本课之后）**：i18n 是**纯显示层关注点**——只在 Qt 侧的 `trc`/`trd` 薄包装、`datum.c` 的基准读数名、以及 C 自绘 chrome/菜单（`window.c`）被调用；**C 渲染核心一行都不碰**。所以它既没有破坏"核心零 SDL"（第 11 课），也没有在 `utils/map/route/render` 与 `ui_qt` 之间引入反向依赖——`skedaddle_i18n` 是个叶子库，被 `ui`/`settings` 单向链接（`CMakeLists.txt:230,562`）。
- **下游 · 第 13 课 datum**：`datum.c:339` 用 `i18n_tr` 出基准名，所以切语言时网格/右下角读数标签也跟着变（"Beijing 1954" ↔ "北京1954"）——这就是 i18n "只动显示读数" 的一个具体落点。
- **验收 · 第 11 课纪律**：i18n 的设计让**回归仍以 zh 为基准语言**（`skedaddle` 默认 `lang=0`），像素/UI 判据完全不受它影响——这是"确定性量 > 时间"之外的又一道"默认零干扰"保险。目前**还没有 `skedaddle_i18n_selftest`**（缺口），可作为练习补一条：断言 `i18n_tr("设置")` 在 zh 模式 `== "设置"`、在 en 模式 `== "Settings"`（纯文本确定性量，不依赖图形）。

## 演示、练习与验收

- **演示**：`cd tutorial/14_i18n && gcc -std=c11 -O2 -Wall -o tut main.c && ./tut`，看五个场景——`[A]` 中文原样返回、`[B]` 内置英文兜底、`[C]` 文件覆盖内置（`lang/en.xml` 把"设置"译成 Preferences）、`[D]` 缺译回退中文原文、`[E]` 新增法语只译"搜索"其余回退英文。
- **练习**（见 `tutorial/14_i18n/README.md`）：
  ① **负向对照**：删掉 `g_tr[]` 里 `"设置"` 且让 `lang/en.xml` 不存在，再跑——应回退中文 `"设置"`，证明"绝不空串"判据真的起作用（对照 `i18n.c` 的 `return zh` 兜底）；
  ② **加一门语言**：在 `g_langs[]` 加一项 + 写 `lang/de.xml`，把 `extract_tag` 的标签改成对应语言，验证 `"搜索"→"Suchen"`；
  ③ **接回真实库**：改成 `#include "i18n/i18n.h"` 并链接 `skedaddle_i18n`，用真实 `i18n_set_lang/i18n_tr` 跑同样五个场景。
- **验收**：能说清"为什么中文是 msgid 既安全又低侵入""回退链为什么以 `return zh` 收底""加一门语言的三步"，并解释 i18n 为什么没有破坏"核心零 SDL / 纯 DAG 分层"。
